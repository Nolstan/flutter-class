# Flutter Practice and Mobile Solutions

This repository documents my practical learning journey in Flutter and Dart as part of the Mobile Solutions module in my BSc in Information Technology degree. It contains a collection of hands-on exercises, UI implementations, navigation examples, and API integration tasks completed throughout the semester.

The project is designed to demonstrate my understanding of mobile application development and to serve as a portfolio of the core Flutter concepts I have explored in class and through self-practice.

## Overview

This repository includes exercises and examples covering:

- Flutter and Dart fundamentals
- Widget-based UI development
- Layout design using containers, rows, columns, and spacing
- Interactive widgets such as forms, switches, and dropdowns
- Lists, cards, and reusable UI patterns
- Screen navigation and passing data between pages
- HTTP requests using GET and POST methods
- Product interface design and e-commerce style screens
- Stateful widget patterns for dynamic UI updates

## Project Structure

The app is organised around a series of topic-based examples and practice screens, including:

- Basic widgets and layout fundamentals
- Navigation and screen transitions
- Forms and user input handling
- Drop-downs and switches
- Lists, tiles, and card-based UIs
- Networking examples with API calls
- Product listing, details, and add-product screens
- Gesture-driven interactions and UI feedback

## Learning Objectives

This project was created to strengthen practical understanding in:

- Building responsive and user-friendly mobile interfaces
- Structuring Flutter applications cleanly and efficiently
- Managing state in interactive components
- Implementing real-world app patterns
- Working with external data sources through APIs
- Developing reusable UI examples for future projects

## Tools and Technologies

## Purpose

This repository acts as a record of my learning progress and technical development in mobile app creation. It reflects both the coursework covered in class and the practical application of those concepts in real Flutter examples.

It is intended to be useful for fellow students, developers, and anyone interested in exploring beginner to intermediate Flutter development patterns in a structured learning environment.
